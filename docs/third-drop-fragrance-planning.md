## 2. 包裝與商品形式

目前包裝方向：

- 霧面塑膠噴霧瓶
- 黑色或深色瓶蓋
- 瓶蓋上加入虎爺公仔
- 公仔參考方向：小型立體虎爺，作為武德宮與守護意象的主辨識
- 香味本身走現代、生活化、精品化，不做成傳統宮廟紀念品味道

重要判斷：

> 虎爺公仔已經負責文化辨識度；香味本身要做到拿掉武德宮 Logo 與虎爺公仔後，一般消費者仍然覺得好聞、願意日常使用。

---

## 3. 總體定位

目前最適合的方向是：

> **Aesop 式精品木質感 + MUJI 式乾淨親和感 + 武德宮虎爺守護故事**

不希望做成：

- 很強烈的宮廟線香味
- 中藥草味
- 傳統芳療館味
- 防蚊液味
- 清潔劑味
- 太甜、太粉、太女性化的香水味

兩款商品不是單純「一瓶淨化、一瓶助眠」，而是形成一個使用情境：

> **白天守空間，晚上守好眠。**

---

## 4. 目前最重要的策略修正

原本構想是讓兩款都以「佛手柑 + 檜木 + 雪松」作為主要骨架，再靠中段不同來區分淨化與睡眠。

但目前判斷這樣風險較高，因為兩款可能聞起來太像，消費者只會覺得：

> 一瓶比較清爽，一瓶比較柔和。

這樣雙 SKU 的購買理由不足。

因此現在調整成：

> **先把淨化款與睡眠款的底層香氣情緒拉開，再用少量共同木質基底維持系列感。**

兩款應該像同一個品牌，但不能像同一支香的兩個版本。

---

## 5. 共同香氣 DNA：虎爺木質基底

可以保留一個共同的「虎爺木質 DNA」，但比例不要太高。

建議共同基底只抓 **10–20% 的嗅覺存在感**，主要是：

- 檜木感
- 雪松感
- 乾淨、安定、不厚重的木質尾韻

目的：

- 讓兩瓶聞得出來屬於同一個系列
- 讓虎爺守護感有一個穩定的嗅覺底座
- 未來如果延伸招財、專注、好運，也能延續同一個系列氣質

但要避免共同基底太重，導致淨化與睡眠聞起來過度接近。

---

## 6. 淨化款方向

### 6.1 香氣性格

淨化款不做傳統「避邪草藥味」，而是偏向：

> **冷、乾、綠、透。**

希望讓人聯想到：

- 空氣被打開
- 森林與草木
- 空間被重新整理
- 清醒、乾淨、守護

### 6.2 建議香氣骨架

目前建議方向：

> **柚子／少量佛手柑 → 絲柏／檜木 → 微量艾草 → 雪松／少量乳香**

各成分角色：

- **柚子／佛手柑**：開頭明亮、乾淨，但不要太甜
- **絲柏**：增加森林、針葉、冷綠感
- **檜木**：建立日式木質與空間潔淨感
- **艾草**：作為淨化／避邪的文化錨點，不作為主香調
- **雪松**：乾燥木質基底
- **乳香**：增加安定與儀式感，但只能少量，避免變線香

### 6.3 艾草策略

艾草不是主香調，而是「故事成分」。

淨化／避邪的可信度，需要一個消費者聽得懂的民俗淨化符號，艾草最適合承擔這個角色。

但艾草如果太重，容易變成：

- 草藥包
- 中藥店
- 藥膏感
- 青草茶感

因此建議打樣不是做「有艾草／無艾草」兩版，而是做同一個精品木質基底下的艾草濃度階梯：

| 樣本 | 艾草存在感 | 目的 |
|---|---|---|
| P0 | 無艾草 | 內部基準，不作商品候選 |
| P1 | 痕量艾草 | 保留成分故事，幾乎不影響香氣 |
| P2 | 微量艾草 | 最可能成為商品候選 |
| P3 | 明顯艾草 | 測試可接受上限 |

我們希望最後即使艾草比例低，也能在成分與文案上保留「含艾草」的文化價值，但香味不要變成草藥商品。

### 6.4 淨化款要避免

- 艾草過重 → 中藥味、草藥包
- 香茅過重 → 防蚊液
- 乳香／檀香過重 → 宮廟、線香、佛具店
- 尤加利／薄荷過重 → 藥膏、清潔劑
- 葡萄柚過重 → 浴室芳香劑或清潔感太強

---

## 7. 睡眠款方向

### 7.1 香氣性格

睡眠款不做傳統「薰衣草助眠噴霧」，而是偏向：

> **柔、圓、暖、靜。**

希望讓人聯想到：

- 晚上洗完澡
- 準備關燈
- 乾淨床單
- 房間慢慢安靜下來
- 安心、柔和、被包覆

### 7.2 建議香氣骨架

目前建議方向：

> **佛手柑／少量甜橙 → 苦橙葉／少量薰衣草 → 柔木／雪松／淡檀木感**

各成分角色：

- **佛手柑**：乾淨、成熟、不甜膩的柑橘
- **甜橙**：增加親和、溫暖、柔軟感
- **苦橙葉**：把柑橘順接到綠葉與木質，提升成熟度
- **薰衣草**：提供睡眠聯想，但不一定要成為主角
- **柔木／雪松**：提供乾淨、安定的底座
- **淡檀木感**：只作柔和尾韻，不要做成線香或宗教感

### 7.3 薰衣草策略

睡眠款不一定需要明顯薰衣草。

薰衣草的好處是消費者容易理解「睡眠／放鬆」，但風險是太容易變成普通芳療噴霧或洗衣精感。

因此建議第一次打樣只測一個關鍵問題：

> **有薰衣草是否真的比較好，還是沒有薰衣草反而更高級、更耐聞？**

建議打樣：

| 樣本 | 方向 | 目的 |
|---|---|---|
| S1 | 佛手柑／甜橙／苦橙葉／柔木／雪松 | 無明顯薰衣草基準版 |
| S2 | S1 + 少量薰衣草 | 測試是否增加睡眠感 |
| S3 | S1 + 更柔和木質尾韻 | 測試更精品、更安靜的版本 |

目前不建議一開始就做濃薰衣草版本。

### 7.4 睡眠款要避免

- 明顯薰衣草精油味
- 芳療館味
- 爽身粉／嬰兒粉味
- 太甜、太香水感
- 檀香過重造成線香感
- 與淨化款聞起來太像

## 8. 成分搭配的依據與目前未知

目前建議不是隨機把成分放在一起，而是來自三個成熟香氛方向的交集：

1. **Aesop Tacit 類型**：柚子／綠色草本／木質，證明「清新綠木質」是成熟精品香氛架構
2. **Aesop Hwyl 類型**：絲柏／乳香／雪松，證明「森林木質 + 樹脂感」可以形成高級木質調
3. **MUJI 睡眠香氛方向**：佛手柑／甜橙／木質，證明「柑橘木質」也可以成立為睡前香氣，不一定需要重薰衣草

但仍有兩個必須靠打樣驗證的未知：

1. **淨化款：艾草加到什麼程度，既保留故事，又不破壞香味？**
2. **睡眠款：薰衣草到底要不要出現？出現到什麼程度最舒服？**

## 9. 第一次打樣需求

### 9.1 我們不是要工廠直接給正式配方

洽談重點是：

> 請英易生技先理解香氣方向，並協助做第一輪測試樣。

不要一開始就鎖死比例與正式配方。

### 9.2 建議第一輪樣本

淨化款：

- 先建立同一個精品綠木質基底
- 基底方向：柚子／少量佛手柑／絲柏／檜木／雪松／少量乳香
- 在同一基底上做艾草濃度階梯：P0、P1、P2、P3

睡眠款：

- 先建立柔和柑橘木質基底
- 基底方向：佛手柑／少量甜橙／苦橙葉／柔木／雪松
- 測試：S1 無薰衣草、S2 少量薰衣草、S3 更柔和木質尾韻

建議完整版本：

- 淨化 4 支：P0 / P1 / P2 / P3
- 睡眠 3 支：S1 / S2 / S3
- 合計 7 支

若工廠認為第一輪樣本數過多，可壓縮為：

- 淨化 3 支：P1 / P2 / P3
- 睡眠 2 支：S1 / S2
- 合計 5 支

## 10. 試聞與盲測方式

收到第一輪樣品後，不要只問「哪一瓶比較好聞」。

每支樣本應記錄：

1. 你覺得它比較像白天還是晚上？
2. 你會把它用在什麼情境？
3. 用三個形容詞描述它
4. 願不願意每天使用？1–5 分
5. 你覺得它像淨化、睡眠，還是都不像？

通過標準：

- 淨化款自然被歸到白天、回家、整理房間、空間重新整理
- 睡眠款自然被歸到晚上、洗澡後、床邊、臥室、放鬆
- 兩款聞起來屬於同一個世界，但不能像同一支香的濃淡版本

## 11. 量產與包材需確認

因為本案有「香氛液體 + 塑膠噴霧瓶 + 噴頭 + 虎爺公仔 + 公仔塗裝／黏膠」，需要與工廠確認完整相容性。

需確認：

- 建議容量：例如 30ml、50ml、100ml 或其他容量
- 兩款各 500 瓶是否符合 MOQ
- 500 瓶對應的原料公斤數與單價
- 香氛液體是否會影響塑膠瓶身
- 是否會變形、龜裂、滲漏、變色
- 噴頭是否容易堵塞
- 公仔材質、塗裝、黏膠是否受香氛液體或揮發物影響
- 是否可噴空間、衣物、寢具
- 若可噴織物，要測殘留、染色與安全規範
- 是否提供 MSDS、SGS、安全檢驗或其他必要文件
- 文案與標示避免醫療化，不宣稱治療失眠或真正避邪效果
