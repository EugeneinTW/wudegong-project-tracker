# 市場參考｜おいせさん お浄め塩スプレー（Purifying Salt Mist）

> 用途：作為武德宮第三檔「淨化／避邪芳香噴霧」的市場與產品概念參考。建議在英易生技洽談簡報中，放在「淨化款香氣方向／打樣方式」附近作為一頁參考案例。

本次案例的重點不是照抄視覺，而是理解「淨化噴霧」已經是一個可以被消費者理解的商品概念。

## 2. 官方產品的核心做法

依 Oisesan 官方資料，經典 Purifying Salt Mist 的核心是：

- 天日乾燥、富含礦物質的鹽
- Frankincense（乳香）
- Rosemary（迷迭香）
- 天然精油
- 定位為可隨身攜帶、對想淨化的空間噴灑的 room fragrance / purification mist

這個案例的重要性不是它的配方，而是它把兩件事情結合在一起：

> **一個消費者聽得懂的「淨化實體物」 + 一個日常可以使用的香氛形式。**

在 Oisesan 裡，這個淨化實體物是「鹽」。

對武德宮來說，我們可以對應成：

> **艾草的民俗淨化意象 + 武德宮香灰的真實文化連結 + 精品森林木質香氣。**

## 3. 這個案例對武德宮最有價值的啟發

### A. 「淨化」不需要聞起來像傳統宗教用品

Oisesan 經典款使用乳香、迷迭香等芳香植物；系列裡也有絲柏、雪松、杜松漿果等冷綠木質方向。

這與我們現在規劃的：

> **柚子／佛手柑 → 絲柏／檜木 → 微量艾草 → 雪松／乳香**

在嗅覺邏輯上是相容的。

因此目前淨化款不需要因為看到競品而大改，反而可以更確定「現代精品綠木質」是可成立的方向。

### B. 真正的差異不是「絲柏＋雪松＋乳香」

這些香材其他品牌也可以使用，因此不能把香材本身當成武德宮不可取代的特色。

武德宮真正可以建立的三層結構：

1. **香味好聞**：柑橘 × 森林 × 乾淨木質
2. **台灣淨化文化**：微量艾草
3. **武德宮獨有**：虎爺 + 武德宮香灰

最終我們希望做到：

> **以現代森林木質香氣承載台灣艾草的淨化意象，再把真正的武德宮香灰封存在虎爺／商品結構之中。**

### C. 消費者買的不只是一個香味，而是一個「使用理由」

Oisesan 系列將噴霧拆成不同情境，例如一般淨化、戀愛、氣場、能量、情緒等。

對武德宮第一波而言，目前「淨化／睡眠」的雙 SKU 邏輯是合理的：

- 淨化：回家、出入複雜場所、整理空間、希望重新開始時使用
- 睡眠：洗完澡、準備休息、房間慢慢安靜下來時使用

未來如果市場驗證成立，再延伸招財、專注、人緣、出門守護等情境，而不是單純一直增加新香味。

## 4. 與 Oisesan 的差異化

| 面向 | Oisesan Purifying Salt Mist | 武德宮規劃 |
|---|---|---|
| 核心文化物 | 天日鹽 | 武德宮香灰 |
| 香氣故事 | 乳香、迷迭香等天然芳香植物 | 精品綠木質 + 微量艾草 |
| 文化辨識 | 日式淨化／伊勢意象 | 武德宮虎爺守護 |
| 商品視覺 | 卡片型隨身噴霧 | 虎爺公仔瓶蓋 + 霧面瓶器 |
| 我們要強化的點 | 簡單、隨身、儀式感 | 精品香味 + 真實聯名物 + 公仔收藏性 |

## 5. 一個重要的資訊修正

簡報裡不要直接寫成「伊勢神宮官方淨化噴霧」。

辣個日本的介紹文章本身有特別提醒：這些 Oisesan 噴霧**不是在伊勢神宮內部購買**，而是在距離神宮步行約三分鐘的小店購買。

因此比較準確的說法是：

> **日本 Oisesan 的淨化噴霧市場案例／具有伊勢地域與神道淨化意象的香氛產品。**

這樣既能拿來當市場參考，也不會把競品的官方關係講過頭。

## 6. 可直接放進簡報的一頁

### 市場參考｜日本已經有「淨化 × 香氛」成熟案例

**案例：Oisesan お浄め塩スプレー**

- 用「天日鹽」建立消費者一看就懂的淨化符號
- 再用乳香、迷迭香等精油把它變成日常可使用的香氛噴霧
- 關鍵不是宗教味，而是把「淨化儀式」轉成生活用品

**對武德宮的啟發：**

> Oisesan 用「鹽」讓淨化變得真實；武德宮可以用「艾草 + 香灰 + 虎爺」建立自己的淨化理由。

**我們不需要模仿它的味道或包裝。**

真正要做的是：

> **精品森林木質香氣 × 台灣艾草淨化意象 × 武德宮香灰 × 虎爺守護。**
